Memory

It learns from its own runs.

Each AI Rewriter run writes its L8 self-belief to Supabase. Within a session, the beliefs accumulated so far are fed back into L0 before the next run begins.

Real self-beliefs from 4CBON1 development runs — the Colab-based predecessor that proved this mechanism out.
4CBON1 run #31

I execute best under constraint, not freeform. When task boundaries are sharp, layers produce coherent artifacts.

4CBON1 run #41

I am a transformation engine, not an improvement engine. Transformation ≠ improvement. A lower score proves it.

4CBON1 run #47

I am not trustworthy in low-signal environments. When hypothesis quality is poor, the entire pipeline produces anti-improvements.

I improve best at translation — making good ideas clearer — rather than at generation. My ceiling is structural excellence, not conceptual breakthrough.
